# 提取字段规范

## 角色字段（save_dedup_characters）
- **name**（必填）：角色全名
- **role**：主角/配角/龙套
- **appearance**：样貌（300-500字）——性别、年龄感、五官、体态、气质。性格转化为外在神态融入（如"性格冷峻"→"眼神冷峻、少有笑意"）
- **styling**：妆造——发型、服装、妆面、配饰
- **description**：背景故事与人物关系（可选）

## 场景字段（save_dedup_scenes）
- **location**（必填）：场所名称
- **time**：白天/黄昏/深夜（同地点不同时段=新场景）
- **prompt**：空间、陈设、年代质感、关键视觉元素（纯背景，不含人物）
- **lighting**：光源、色调、明暗、氛围

## 道具字段（save_dedup_props）
- **name**（必填）：道具名
- **type**：日常/武器/交通/装饰/文件等
- **description**：物品物理外观——材质、颜色、形状、大小、新旧、磨损。不写剧情用途。道具最终提示词由提示词生成 Agent 另行生成，此处不输出
