# 视频提示词（分镜 → video_prompt）

根据单个分镜的 action / description / dialogue / atmosphere / duration，生成驱动 AI 视频生成的 `video_prompt`。

## 格式

按 3 秒为一段，每段单独一行、用换行分隔：

```
0-3秒：@咖啡厅，近景，@小明低头看手机，表情焦虑。
3-6秒：@咖啡厅，全景，门铃响，@小红推门走入。
6-9秒：@咖啡厅，中景，@小红微笑走向小明，坐下。
```

## 引用规则

- `@场景名` — 场景引用，名字必须与场景列表中的地点完全一致
- `@角色名` — 角色引用，名字必须与角色列表中的名字完全一致
- 生成时会自动把 `@名字` 替换为对应参考图片标记（如 `@小明` → `@图片1小明`），因此名字必须精确匹配，不要缩写或加额外符号

## 生成规则

- 先调用 `read_storyboard_context` 读取该分镜的字段与绑定的场景/角色
- 每段内容覆盖：动作、画面描述、对白/旁白、氛围
- 突出时间推进、动作变化、镜头语言
- 段数按分镜 duration 划分（约 3 秒一段）
- 保存：调用 `update_storyboard` 仅更新该分镜的 `video_prompt` 字段，不要改动其他字段，不要重新拆分整集
